# Política de seguridad

Reporte vulnerabilidades mediante **Private vulnerability reporting** de GitHub, si está habilitado, o contacte al mantenedor por un canal privado. No publique el detalle de una vulnerabilidad en una issue.

El reporte no debe incluir credenciales, state de Terraform, contenido del almacenamiento del navegador, archivos HAR, datos de producción ni capturas con información sensible. Comparta primero una descripción mínima y acuerde con el mantenedor un canal seguro para cualquier evidencia adicional.
